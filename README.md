# Showtime camera test

Phase 0 of the Showtime Driver Telegram Mini App: one web page that opens the phone's
camera, takes three quick shots of a DigiVan screen and reports sharpness, light,
LED banding and what the phone's camera allows. Nothing is saved or uploaded.

Source of truth: `web/camera-test/index.html` in the private `showtime-connect-driver-app`
repository. This public repository exists only so GitHub Pages can serve the page.
